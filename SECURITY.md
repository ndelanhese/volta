# Security and privacy

Volta controls other windows through macOS Accessibility and stores window metadata locally.
Snapshots and logs may include application names and document/window titles. They should not be
committed or attached to public issues without removing personal information.

Report vulnerabilities through this repository's **Security → Report a vulnerability** feature.
For ordinary bugs, use Issues. Do not include credentials, private keys, personal window titles,
or unredacted local databases in either a report or an attachment.

Current support is best effort for the latest preview release. There is no guaranteed response time.
Volta does not need disabled SIP, globally disabled Gatekeeper, or unrestricted disk access.
